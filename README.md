# 🔐 Generador de Contraseñas

Este es un generador de contraseñas aleatorias con evaluación de seguridad incorporada. Podés ingresar la cantidad de caracteres deseada y obtener una contraseña segura de forma instantánea.

## ⚙️ Tecnologías usadas

- HTML5
- CSS3 (con gradientes y sombras modernas)
- JavaScript (DOM, validación y lógica de seguridad)

---

## 💡 Funcionalidades

- Generación de contraseñas aleatorias.
- Evaluación visual del nivel de seguridad (`Débil`, `Media`, `Fuerte`).
- Validación del campo de cantidad.
- Diseño responsivo y moderno.
